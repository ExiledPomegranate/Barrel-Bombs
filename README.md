Minecraft mod that adds a new explosive

Inspired by [u/-C-7007's idea from r/MinecraftSuggestions](https://www.reddit.com/r/minecraftsuggestions/comments/1kmrqhx/explosive_barrel_a_better_explosive_for_tunnels/)
Requires the [Architectury API](https://modrinth.com/mod/architectury-api)

Very powerful explosive. Don't worry though, it drops few items (and never ancient debris (configurable)) so that way it isn't too OP

![Crafting Recipe. 4 blaze powder in the corners, 4 gunpowder along the edges, barrel in the center.](https://cdn.modrinth.com/data/cached_images/61aabcd392f7c698eb517eb570534863944bf6b9.png)

Features:
- More consistent than TNT, no gravity
- Partially ignores blast resistance, good for Basalt Deltas
- Directional, explosions extend forward in the direction the bomb is facing
- Right click with Blaze Powder to extend forward range; Gunpowder increases blast radius (32 max) (put stack in offhand to use entire stack)
- Faces away from you when placed, hold shift to make it face toward you
- Meant for making holes, does less damage to players and has anti-griefing measures
- Can be configured with command (some options can only be changed in config file)
